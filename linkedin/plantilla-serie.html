4 Rate Limiting Algorithms

Jesús Cabrerageminislabs.com
01
Token
Bucket
Tokens refill at a fixed rate. Each request spends one.
Best for:
Bursty APIs
allow if tokens ≥ 1
Allows bursts up to the bucket size, then the refill rate.
02
Leaky
Bucket
Requests queue up and drain at a constant rate.
Best for:
Smooth output
out rate = r (fixed)
Absorbs spikes by queueing them. nginx limit_req works this way.
03
Fixed
Window
Count requests per clock window. Reset at the edge.
Best for:
Simple quotas
count[minute] ≤ N
One counter per key. Weak spot: bursts at the window edge.
04
Sliding
Window
Weight the previous window to smooth the edge.
Best for:
Accurate limits
prev × overlap + curr ≤ N
Close to exact with only two counters per key.
